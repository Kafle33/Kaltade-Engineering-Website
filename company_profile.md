## 3. WEBSITE OBJECTIVE

The website should accomplish five major things:

1. **Establish Kaltade’s Professional Identity**  
   Visitors should immediately understand that Kaltade is a professional engineering and property consultancy.

2. **Generate Leads**  
   Visitors should be able to easily:
   - Request a valuation
   - Request engineering services
   - Request a DPR
   - Find a property
   - List a property
   - Request property consultation
   - Contact the company

3. **Build a Property Database**  
   The website should eventually allow Kaltade to maintain a database of properties available for sale or rent.

4. **Build Institutional Credibility**  
   The website should present Kaltade professionally to:
   - Banks
   - BFIs
   - Investors
   - Developers
   - Businesses
   - Property owners
   - Individual clients

5. **Support Future Expansion**  
   The website should be built so that Kaltade can gradually expand into a larger real-estate platform.

## 40. LEGAL & COMPLIANCE

This is particularly important for the real-estate section.

The website must not claim that Kaltade is a:

- Licensed real-estate broker
- Authorized property dealer
- Government-authorized transaction company
- Licensed real-estate transaction operator

unless the relevant licence/authorization has actually been obtained.

Until then, use terms such as:

- Real Estate Consultancy
- Property Consultancy
- Property Assessment
- Property Investment Consultancy
- Property Transaction Assistance, subject to applicable authorization

Similarly, only publish professional registrations, licences, certifications and institutional authorizations that can be verified.

## 44. MOST IMPORTANT INSTRUCTION TO THE CODER

**Do not build Kaltade as just a static company-profile website.**

Build it as a **scalable business platform**.

The initial version should present:

**Engineering Consultancy + Property Valuation + Real Estate Consultancy**

but the architecture should allow Kaltade to eventually develop into:

**Engineering Services + Valuation Platform + Property Marketplace + Real Estate Consultancy + Property Investment Platform**

The website should therefore be built with a strong CMS, property database, inquiry/lead management system, SEO structure and scalable backend from the beginning.
